# MURADESC

Mural Digital Escolar desenvolvido no Projeto Integrador Extensionista.

## Requisitos

- Git
- Vite+ (comando vp): https://viteplus.dev

## Como rodar o projeto

1. Clone o repositório e entre na pasta:
   git clone [suspicious link removed]
   cd MURADESC
2. Instale as dependências: vp install
3. Copie `.env.example` para `.env`
4. No Terminal 1, inicie a API: vp run api
5. No Terminal 2, inicie o frontend: vp dev
6. Abra o navegador em: http://localhost:5173
